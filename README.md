# B站首页频道过滤器

一个用于 Tampermonkey 的 B站网页版首页推荐流过滤脚本。

它可以在 `https://www.bilibili.com/` 首页中，根据 B站频道分类过滤推荐卡片，让你自己决定首页显示哪些内容。

## 功能特点

- 只作用于 B站网页版首页，不影响视频播放页、搜索页、用户空间、番剧页、直播页等页面。
- 支持首页推荐流动态加载、无限滚动和 SPA 局部更新。
- 使用 `MutationObserver` 监听新增卡片，避免高频全页面扫描。
- 不删除 DOM，只使用 `display: none !important` 隐藏完整卡片容器。
- 支持设置面板，按 B站频道分类独立开关。
- 配置会保存到浏览器 `localStorage`，刷新页面后继续生效。
- 默认保守策略：无法确认分类的普通视频默认保留，尽量避免误删。

## 支持过滤的分类

脚本内置多列频道面板，支持以下分类：

- 番剧、电影、国创、电视剧、综艺、纪录片、动画、漫画、游戏、鬼畜、音乐
- 舞蹈、影视、娱乐、知识、科技数码、资讯、美食、小剧场、汽车、时尚美妆
- 体育运动、动物、vlog、生活、绘画、家装房产、户外、健身、手工、旅游出行
- 三农、亲子、健康、情感、生活兴趣、生活经验、公益、超高清、视频播客
- 专栏、直播、活动、课堂、社区中心、新歌热榜

同时保留对以下特殊卡片的识别：

- 赛事 / 电竞赛事
- 直播 / 直播间推荐
- 广告 / 推广 / 商业卡片
- 商品推广
- 话题卡片
- 活动卡片
- 其他特殊推荐卡片

## 安装方式

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 新建脚本。
3. 将 `B站首页普通视频净化.user.js` 中的完整代码复制进去。
4. 保存脚本。
5. 打开或刷新 [B站首页](https://www.bilibili.com/)。

## 使用方式

打开 B站首页后，页面右下角会出现一个设置按钮。

点击设置按钮，可以打开“B站首页内容过滤”面板：

- 勾选某个分类：显示该分类内容。
- 取消勾选某个分类：隐藏该分类内容。
- `全部开启`：显示所有分类。
- `全部关闭`：隐藏所有可识别分类。
- `恢复默认`：恢复默认配置。
- `立即应用`：重新应用当前配置。

面板还支持搜索分类，例如输入：

- `游戏`
- `生活`
- `科技`
- `漫画`

## 识别策略

脚本不会简单粗暴地根据标题关键词删除内容。

识别优先级大致如下：

1. 视频或卡片跳转 URL
2. 卡片 DOM 结构
3. class / data 属性
4. 卡片内部频道、标签、角标信息
5. B站已有分类标识
6. 非常保守的标题兜底规则

对于普通视频，如果无法可靠识别频道，脚本默认保留。

## 调试方法

如果需要排查某张卡片为什么被隐藏或保留，可以把脚本中的：

```js
const DEBUG = false;
```

改为：

```js
const DEBUG = true;
```

然后打开浏览器控制台查看 `[BiliClean]` 日志。

也可以在 DevTools 中选中某个推荐卡片 DOM 后执行：

```js
BiliHomeCleanerDebug.classify($0)
```

查看该卡片的识别结果。

脚本处理过的卡片会带有调试属性：

- `data-bili-cleaned="true"`
- `data-bili-clean-type="..."`
- `data-bili-clean-channel="..."`

## 注意事项

- B站首页 DOM 结构可能随时变化，脚本已经尽量使用多层规则降低失效概率。
- 如果 B站没有在首页卡片中暴露明确频道信息，部分普通视频可能无法分类，这类视频会默认保留。
- 脚本不会修改 B站接口，不发送任何数据，不依赖第三方服务。
- 本脚本只匹配 `https://www.bilibili.com/` 首页。
